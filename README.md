# Asteroid Viewer

created as part of the [LSST SSSC First Data Sprint](https://lsst-sssc.github.io/Sprint2026/index.html) in Belfast, NI in February 2026.

## Setup

Recommended to use VSCode to edit and run the app.

1. Install `VS Code's Live Server`.
2. Right click on the `index.html` and select `Open with Live Server` or use the command palette (cmd + shift + p) and use the extension command above to start a local development server.


## Features
- Different Textures
  - Gray
  - Grid of longitude/latitude

- Optional Controls
  - Switch texture
  - Overlay information
    - Scale bar
    - Name of target
    - SEP and SSP coordinates?

- Different views
  1. Plane of the sky static
  2. Plane of the sky rotation w/ time (could be same as #1 with control)
  3. Free motion from click 'n' drag
  4. Orbit in the Solar System
     - With planets
     - With Gaia stellar background
